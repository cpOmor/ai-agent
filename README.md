## 🚀 যেভাবে চালাবেন (How to Run)

### ১. সুন্দর ওয়েব ইন্টারফেসে কথা বলতে (Web UI):
- ফোল্ডারে থাকা **`start-web.bat`** ফাইলে ডাবল-ক্লিক করুন।
- অথবা টার্মিনালে রান করুন:
  ```bash
  npm start
  ```
- এরপর ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন হবে।

### ২. সরাসরি টার্মিনাল / কনসোলে কথা বলতে (CLI Mode):
- ফোল্ডারে থাকা **`start-cli.bat`** ফাইলে ডাবল-ক্লিক করুন।
- অথবা টার্মিনালে রান করুন:
  ```bash
  npm run cli
  ```
- কম্যান্ডস:
  - `clear` - চ্যাট হিস্ট্রি রিসেট করতে।
  - `exit` - চ্যাট বন্ধ করতে।
